# GalleryCleaner 수익모델 추천

> 체크 항목: 0단계 `revenue` (수익모델 결정 근거). **결정은 사용자 몫** — 이 문서는 현재 코드 기준 사실과 추천안만 정리한다.
> 작성 기준 브랜치: `feature/perf-scan-optimization` (2026-10-04). 가격·수치는 가정이며 출시 전 Play Console에서 확인 필요.

## 1. 현재 코드에 이미 구현된 것 (사실)

| 요소 | 구현 위치 | 동작 |
|---|---|---|
| 리워드 광고 게이트 | `AdGateImpl.unlock()`, `MainViewModel.scan()` | 스캔 시작 전 `isUnlocked()` 확인 → 아니면 리워드 광고 다이얼로그. 광고 시청 시 **1시간** 동안 스캔 허용 |
| 배너 광고 | `BannerAdView` (`MainActivity`의 `scanningBanner`) | 스캔 진행 화면에만 표시 |
| 평생 구매 (IAP) | `AdGateImpl`, 상품 ID `gallerycleaner_premium_lifetime` (INAPP, Billing 7.1.1) | 구매 시 `isPremium=true`, 앱 시작 시 Play 기록으로 복원, acknowledge 처리 |
| 프리미엄 혜택 (설정 화면 문구) | `SettingsSheet.PremiumCard` | "광고 없이 무제한 스캔·정리", "전체 기간 스캔 잠금 해제" |
| 기간 필터 잠금 | `ScanFilterSheet` (`isPremium`, `onPremiumRequired`) | 가장 긴 기간 옵션은 프리미엄 전용 |
| 광고 ID 관리 | `app/build.gradle.kts` | `local.properties`의 `ADMOB_*` 사용, 없으면 Google 테스트 ID (키 커밋 없음) |

즉 구조는 **"무료(광고 시청 후 1시간 스캔) + 평생 프리미엄 1종"** 하이브리드로 이미 잡혀 있다. 남은 결정은 구조 변경 여부와 가격이다.

## 2. 후보 비교

| 안 | 내용 | 장점 | 단점 / 위험 |
|---|---|---|---|
| A. 현행 유지 (하이브리드) | 리워드 광고 1시간 + 평생 구매 | 추가 개발 0, 출시 일정(D-14)에 안전 | 정리 앱은 "1회 대량 정리 후 이탈"이 흔해 재방문 광고 수익이 작음. 평생 구매가 사실상 주 수익 |
| B. 구독 | 월/연 구독 | 반복 수익 | 사용 패턴이 일회성 → 전환·유지 어려움. 구독 UI·정책(해지 안내 등) 추가 작업 |
| C. 유료 앱 | 설치 유료 | 단순 | 다운로드 급감, 신규 앱 신뢰 없음 |
| D. 완전 무료 + 배너 | 배너만 | 마찰 최소 | 수익 미미, 현 게이트 구조 제거 필요 |

## 3. 추천: **A. 현행 유지 + 마감 전 손볼 3가지**

출시까지 14일이고 구현이 이미 끝나 있으므로, 구조는 바꾸지 말고 아래만 확정하는 것을 추천한다.

1. **가격**: 평생 구매 **₩3,900 ~ ₩4,900** 구간 (가정). 일회성 정리 도구라 부담 없는 가격대가 전환에 유리. 첫 출시가는 ₩3,900 추천, Play Console에서 나중에 조정 가능.
2. **무료 경험 유지**: 첫 스캔 결과를 보기 *전*에 광고 벽이 나오는 현재 흐름은 이탈 위험이 있다. 온보딩 직후 **첫 스캔 1회는 광고 없이 허용**하는 안을 v1.1 후보로 두자(출시 전 필수는 아님).
3. **프리미엄 혜택 문구 일치**: 설정 카드 문구와 실제 잠금(기간 필터, 광고 제거)이 같은지 확인. 스토어 설명(`listing`)에도 동일하게 적을 것.

## 4. 사용자가 직접 해야 하는 것 (클라우드에서 불가)

- Play Console에 INAPP 상품 `gallerycleaner_premium_lifetime` 등록·가격 설정·활성화 (미등록 시 `launchPremiumPurchase`가 로그만 남기고 반환 — `AdGateImpl.kt`)
- 실제 AdMob 앱/광고 단위 생성 후 `local.properties`에 `ADMOB_APP_ID`, `ADMOB_REWARDED_ID`, `ADMOB_BANNER_ID` 설정 (레포에 커밋 금지)
- 라이선스 테스터 계정으로 구매·복원·환불 흐름 실기기 확인
- 설정의 "프리미엄 활성화 (테스트용)" 토글은 `BuildConfig.DEBUG`일 때만 노출되는지 릴리스 빌드에서 확인

## 5. 추정 (참고용, 가정치)

실제 데이터가 없으므로 방향성만 본다. 월 활성 1,000명 가정 시 유료 전환율 2~4%면 20~40건 × 약 ₩3,900 ≈ ₩8만~16만(수수료 전). 광고 수익은 스캔당 리워드 1회 기준으로 소액. **수익보다 출시·리뷰 확보가 우선**이라는 전제로, 가격 실험은 출시 후로 미루는 것이 합리적이다.
